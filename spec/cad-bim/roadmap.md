# CAD/BIM Full-Parity Roadmap v1.0

The goal is **professional workflow parity**, not source-code cloning. AutoCAD provides a broad command-driven 2D/3D drafting model with precision aids, layers, properties, annotations, blocks, layouts, references and specialized toolsets; Autodesk's current documentation also exposes a large command surface and Architecture toolset. citeturn392667search5turn392667search10turn392667search1

Archicad adds a BIM-first model/documentation workflow organized around stories, viewpoints, Navigator, 3D, schedules, Layout Book, Publisher, annotations, revisions and collaboration; current Archicad documentation describes these as integrated project workflows. citeturn328058search6turn328058search8turn328058search5

## Phase 0 — Freeze

Freeze CAD Product Architecture v1.0, lock canonical domain/API/engine/UI boundaries, establish benchmark corpus and acceptance policy.

## Phase 1 — Professional workspace

Command palette/line, ribbon, toolbars, properties, layers, navigator, status bar, tabs, docking, selection, grips, coordinate readout, snaps, contextual menus and keyboard shortcuts.

## Phase 2 — AutoCAD-class 2D core

Primitives, modify operations, precision aids, styles/layers, annotation, hatches, blocks/attributes, references/xrefs, model/paper space, viewports and plotting.

## Phase 3 — Parametric/associative drafting

Geometric/dimensional constraints, deterministic solver, associative dimensions/labels, dynamic block parameters, stretch/grips, arrays/patterns and dependency diagnostics.

## Phase 4 — Professional 3D

UCS/workplanes, navigation, solids/surfaces/meshes, booleans, section/clipping, materials, visual styles, feature histories and large-model performance.

## Phase 5 — Archicad-class BIM authoring

Stories/levels, walls/slabs/roofs, doors/windows/openings, stairs/railings, zones/spaces, composites/profiles, objects/components, materials, classification/properties, design options and renovation states.

## Phase 6 — Documentation production

Navigator/project map, views, details, sections/elevations, associative documentation, layouts, master layouts, subsets, title blocks, schedules, indexes, revisions and publisher sets. Archicad's current documentation explicitly includes these areas. citeturn328058search6turn328058search8

## Phase 7 — Interoperability

IFC, IDS, BCF, DXF, DWG boundary, PDF/SVG plotting, native archival formats where legally compatible, robust source lineage and round-trip benchmarks.

## Phase 8 — Collaboration and scale

Autosave/recovery, crash recovery, multi-user review, comments, presence, external references, large-model streaming/caching, background regeneration and observable performance budgets.

## Phase 9 — Specialized toolsets

Architecture automation, MEP/electrical, mechanical/detailing, plant/map/raster/point-cloud capabilities as modular extensions rather than changes to the core architecture. AutoCAD currently distributes specialized Architecture, Mechanical, Map 3D, MEP, Electrical, Plant 3D and Raster Design toolsets, which we can use as the parity catalog. citeturn392667search0turn392667search3turn392667search11

## Phase 10 — Certification

Run a representative workflow corpus against target AutoCAD and Archicad workflows. Certification requires semantic result, persisted-artifact, UI task completion and performance evidence. Feature checklists alone do not certify parity.

## Priority principle

We optimize first for the daily workflows that determine user retention: drawing/editing speed, precision, selection, properties/layers, annotation, blocks, model navigation, BIM authoring, documentation, file exchange and recovery.

The product may eventually exceed either reference product by integrating Construction Graph, quantity/estimate/RFQ impact, collaboration and ConstructionOS intelligence directly into CAD/BIM workflows.
